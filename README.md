# CodeFest 2026 — YOLOv8 Object Detection

Computer vision project developed for **CodeFest 2026 by IIT Varanasi**, focused on object detection across 200 categories.

## 🚀 Project Overview

This project involved training and evaluating a custom **YOLOv8** object detection model for a large multi-class computer vision dataset.

The workflow included:

- Dataset preparation
- YOLOv8 model training
- Multiple training experiments
- Model validation
- Performance evaluation
- Test-set inference
- Competition submission generation

## 🧠 Model

- **Model:** YOLOv8 Nano
- **Framework:** Ultralytics
- **Parameters:** 3,370,724
- **Layers:** 168
- **Training epochs:** 5
- **Training time:** 2.79 hours
- **GPU:** NVIDIA GeForce RTX 3050 6GB Laptop GPU
- **CUDA:** cu118
- **Framework:** PyTorch
